柠萌音乐一款本地优先的轻量音乐播放器 —— 曲库以「歌曲扩展包」形式导入，歌词逐字高亮，播放全程不联网、不上传。

**详细介绍**

柠萌音乐把「播放器」和「曲库来源」拆开了。应用本身不带任何版权歌曲，只提供一套干净的播放内核；真正的内容通过 `.zip` 歌曲扩展包装载，包内用 `manifest.json` 描述歌曲与封面。扩展包可以放在手机里从本地导入，也可以粘贴网络链接下载装载，装载完成后曲目直接进入本地曲库，断网照样播。

歌曲市场是扩展包的获取入口，分为精选、热门、最新上新、私人专属四个板块，资源从 GitHub Releases 拉取，支持直连与备用通道自动重试；网络不可用时会回退到上一次缓存的资源列表，不会白屏。

歌词页是这款播放器最舍得下功夫的地方：支持逐字高亮跟随，背景提供四种模式 —— 跟随当前歌曲封面自动换、默认深色渐变（专注读词）、导入静态图片、导入动态视频（循环静音播放）。外观清爽，没有广告位和推荐流。

**核心功能**

- **扩展包曲库**：本地 `.zip` 导入 / 网络链接装载，支持重命名、查看歌曲清单、查看包体积与导入时间、整包删除
- **歌词逐字高亮**：全文歌词页，四种背景样式（封面 / 深色渐变 / 静态图 / 视频）
- **全局播放控制**：前台播放服务 + 通知栏与锁屏媒体控制，授权后可持续后台播放
- **四种播放模式**：列表循环、顺序播放、列表随机、单曲循环
- **听歌数据**：收藏、最近在听、最常播放、听歌总时长、按播放次数排序的歌曲排行榜
- **权限中心**：通知、存储、修改系统设置、后台运行四项权限集中管理，逐项显示授权状态
- **隐私**：首次启动需同意协议；不收集、不上传任何个人身份信息，歌曲与扩展包数据全部落在设备本地
